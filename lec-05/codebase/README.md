# Lecture 5 lab

1. Follow `docker-lab-instructions.txt` from **Git Bash on Windows**.
2. Console (CLI-0 to CLI-3) starts one Amazon Linux EC2. Docker is installed **there**.
3. `scp` the `notes-api/` folder onto the instance. Do not rewrite the Python.
4. Second SSH window: `curl http://127.0.0.1:8080/health` on the EC2.
5. Terminate the instance when you finish. Fill `../assignment.md`.
