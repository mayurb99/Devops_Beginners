Lecture 3 — OPTIONAL practice (not required in class)
The PowerPoint already shows these examples. Skip this file unless you want to try.

No AWS console. Do not create NAT, a load balancer, or EC2.


--------------------------------------------------
A. Optional: a working local call (needs lecture 2 notes-api)
--------------------------------------------------

  cd lec-02/codebase/notes-api
  python notes-api.py

Second window:

  curl -v http://127.0.0.1:8080/health

Look for Connected, then HTTP 200. 127.0.0.1 skips DNS.


--------------------------------------------------
B. Optional: DNS then HTTPS
--------------------------------------------------

  curl -v --max-time 15 https://example.com

Look for: resolve host, port 443, SSL, then HTTP.


--------------------------------------------------
C. Optional: failure names
--------------------------------------------------

  curl -v --max-time 5 http://127.0.0.1:9          # refused
  curl -v --max-time 5 http://192.0.2.1:80         # timeout
  curl -i --max-time 15 https://httpbin.org/status/403   # HTTP 403


--------------------------------------------------
D. Optional: ping and traceroute
--------------------------------------------------

  ping 8.8.8.8
  tracert example.com          # Windows
  traceroute example.com       # Git Bash / Mac / Linux

A failed ping does not always mean the site is down (ICMP is often blocked).


--------------------------------------------------
Do not do
--------------------------------------------------

  Creating a NAT Gateway, load balancer, or EC2
  Opening 0.0.0.0/0 on SSH
  Spending money
