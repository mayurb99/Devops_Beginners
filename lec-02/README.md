# Lecture 2 — REST APIs

75-minute teaching pack. Module 1: Foundations.

**Curriculum:** HTTP/HTTPS, methods, status codes, headers, JSON, API keys and tokens, curl, Postman, one AWS CLI call.

Do not teach Git, VPC, Terraform, Docker, or Kubernetes today. Students **call** notes-api. They do not write it.

## The PowerPoint is written for students to read

`presentation/lec-02-rest-apis.pptx` explains every idea on the slides.

## Learning objectives

1. Describe a request and a response in plain English.
2. Name HTTP methods and what they mean in operations.
3. Read status codes 2xx, 4xx, and 5xx without guessing.
4. Read a small JSON body.
5. Use an API key header and recognise 401.
6. Call notes-api with `curl` (and Postman if installed).

## Lab

Follow `codebase/api-lab-instructions.txt` line by line.

You need two terminals: one to run notes-api, one to call it.
