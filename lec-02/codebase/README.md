# Lecture 2 lab

Use the **existing** course repo. Do not create a new repository. Do not `git init`. Do not `git merge` in the terminal.

Pull request / merge is done in the **GitHub UI**.

## Instruction list

Open and follow, line by line:

`git-demo-instructions.txt`

That file uses this repo:

https://github.com/mayurb99/Devops_Beginners

## What you will type

- `git status`, `git log --oneline`, `git branch`, `git remote -v`
- `git pull`
- `git checkout -b add-my-note`
- edit `notes-api/notes.txt`
- `git diff`, `git restore`, `git add`, `git commit`, `git push`

Then on GitHub: **Create pull request** → **Merge pull request**.

## What you will not type

- `git init`
- `git merge`
- a merge conflict in the terminal
