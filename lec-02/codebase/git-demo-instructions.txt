Lecture 2 Git demo
Repo: https://github.com/mayurb99/Devops_Beginners
Do NOT run git init. Do NOT create a new repository. Do NOT merge from the terminal.
This repo already exists. Merge / pull request is done in the GitHub website (UI).

Open Git Bash. Go to the folder where you cloned this course repo
(example on this laptop):

  cd "C:/Users/mayur_brijwani/Desktop/New folder (2)/Devops_Beginners"


--------------------------------------------------
A. Look around (read-only)
--------------------------------------------------

  git status
      You should be on main (or master). Working tree should be clean.

  git log --oneline
      Short history of this course repo.

  git branch
      Shows local branches. * is the branch you are on.

  git remote -v
      origin should be the GitHub URL above.


--------------------------------------------------
B. Get the latest main
--------------------------------------------------

  git checkout main
  git pull origin main


--------------------------------------------------
C. Work on a branch (never edit main directly)
--------------------------------------------------

  git checkout -b add-my-note

  git branch
      add-my-note should have the *


--------------------------------------------------
D. Change a file, see the diff, practise restore
--------------------------------------------------

Open this file in the editor and add one new line at the bottom:

  lec-02/codebase/notes-api/notes.txt

Example line:

  - I completed the Lecture 2 Git demo

Save the file.

  git status
      notes.txt should show as modified.

  git diff
      You should see your new line with a +.

Undo the change (restore), then add the line again so we still have something to commit:

  git restore lec-02/codebase/notes-api/notes.txt
  git status
      Clean again — restore threw the edit away.

Add the same line to notes.txt a second time and save.

  git diff
  git status


--------------------------------------------------
E. Stage and commit (not git add .)
--------------------------------------------------

  git add lec-02/codebase/notes-api/notes.txt
  git status
      The file should now be staged (ready to commit).

  git diff --staged
      This is what the commit will contain.

  git commit -m "Add my Lecture 2 course note"

  git log --oneline
      Your commit should be at the top.


--------------------------------------------------
F. Push the branch (still no merge in the terminal)
--------------------------------------------------

  git push -u origin add-my-note

If GitHub asks you to log in, complete that, then run the push again.


--------------------------------------------------
G. Create the pull request in the GitHub UI
   (this is the merge. Do not run git merge)
--------------------------------------------------

1. Open https://github.com/mayurb99/Devops_Beginners
2. You should see a yellow banner: Compare & pull request
   Or click Pull requests → New pull request
3. Base branch:  main
   Compare branch:  add-my-note
4. Title:  Add my Lecture 2 course note
5. Description:  one sentence — what you changed and why
6. Click Create pull request
7. Click Merge pull request → Confirm merge
8. Optional: Delete branch on GitHub


--------------------------------------------------
H. Update your laptop after the UI merge
--------------------------------------------------

  git checkout main
  git pull origin main
  git log --oneline
      Your note commit should now be on main.

  git branch
      You can delete the local branch if you want:

  git branch -d add-my-note


--------------------------------------------------
Do not do in this demo
--------------------------------------------------

  git init
  git merge
  Creating a new GitHub repository
  git add .
  Committing .env or any secret
  git push --force
