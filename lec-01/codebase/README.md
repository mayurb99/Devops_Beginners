# Lecture 1 lab

One script. No Python app. No cloud.

## Run

```bash
cd lec-01/codebase
bash linux-basics.sh
```

You will:

1. See who you are and which folder you are in
2. Create a folder and a sample `app.log`
3. Read it with `cat`, `head`, and `tail`
4. Search it with `grep`
5. Copy and rename a file
6. Append a new log line with `>>`
7. Check disk, hostname, and running processes

## Cleanup

```bash
rm -rf devops-linux-demo
```
