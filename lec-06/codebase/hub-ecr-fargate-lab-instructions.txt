Lecture 6 — Docker Hub, ECR, Fargate
Docker still runs on Amazon Linux EC2. Windows has no Docker Desktop.
Console starts the box and the AWS pieces (ECR, Fargate). Git Bash is SSH + curl.

Need on Windows: a browser (AWS console), Git Bash, the same Region as lectures 4–5.
Need a free Docker Hub account (hub.docker.com) before class. Access token, not your Hub password.
You package notes-api. You do not rewrite the Python.
No Docker Compose today. One container — lecture 5’s docker build / docker run is enough.

Clock: about 75 minutes. Do not add extra demos. Cleanup is part of class.

  0–12 min   slides (path, Hub vs ECR, Azure/GCP names, Fargate, money)
 12–25 min   EC2 + docker build + docker run + curl on the box
 25–38 min   Docker Hub push
 38–50 min   ECR create + push
 50–68 min   Fargate run + curl from Windows
 68–75 min   delete everything

Demo E — Amazon ECR (AWS’s shelf)
--------------------------------------------------

   Repository name: notes-api
   Tag immutability: Disabled (class default)

F2. Task definition  (console)

1. ECS → Task definitions → Create new task definition
2. Task definition family: notes-api
3. Launch type: AWS Fargate
4. OS/Architecture: Linux / X86_64
5. CPU: 0.25 vCPU
   Memory: 0.5 GB
6. Task role: None
7. Task execution role: Create new role
   (console makes ecsTaskExecutionRole with AmazonECSTaskExecutionRolePolicy.
    That policy lets Fargate pull from ECR and write CloudWatch logs.
    If the role already exists, select ecsTaskExecutionRole.)
8. Container — 1
   Name: notes
   Image URI: paste $URI:l6
     example: 123456789012.dkr.ecr.ap-south-1.amazonaws.com/notes-api:l6
     Must include :l6. Do not use :latest.
   Port mappings: 8080  TCP  (name http is fine)
   Environment variables → Add
     HOST   =  0.0.0.0
     PORT   =  8080
9. Logging: leave “Use log collection” on (CloudWatch).
10. Create


F3. Service  (console)

1. ECS → Clusters → lec06-cluster → Services → Create
2. Compute options: Launch type  →  Fargate
3. Application type: Service
4. Family: notes-api   Revision: latest (this means latest TASK DEF revision, not the image tag)
5. Service name: notes-svc
6. Desired tasks: 1
7. Networking
   VPC: Default VPC
   Subnets: pick default subnets (they are public — they have an internet gateway)
   Security group: Create a new security group
     Name: lec06-fargate-8080
     Inbound: Custom TCP, port 8080, source 0.0.0.0/0
     (class demo only. Delete today.)
   Public IP: TURNED ON
     If this is off, the task cannot pull ECR without NAT, and you cannot curl it.
8. Load balancing: None
9. Create

Wait until the service is Active and running count = 1.
If the task is STOPPED: open the task → Stopped reason.
  CannotPullContainerError = public IP off, or image URI wrong, or execution role missing.
  ResourceInitializationError = same: no route to ECR. Public IP must be on.

--------------------------------------------------
If something fails
--------------------------------------------------

ssh times out
  SG not My IP, or 2/2 not done, or you used Instance Connect instead of Git Bash.

port is already allocated
  sudo docker rm -f notes-l6
  then docker run again.

docker login Hub: denied
  Use an access token, not the Hub password. Username is Hub username, not email.

ECR login / push: AccessDenied
  Instance profile missing. Modify IAM role on the instance to lec06-ec2-ecr.
  Wait 30 seconds. aws sts get-caller-identity again.

ECR push: repository does not exist
  Create notes-api in THIS Region. URI Region must match REGION.

Fargate task STOPPED CannotPullContainerError
  Public IP was off, or image URI missing :l6, or execution role missing ECR pull.
  Delete the service. Fix the task def / networking. Create the service again.

curl to Fargate hangs
  You used the EC2 IP, or Fargate SG has no 8080, or the task is not RUNNING.

curl to Fargate connection refused
  Container crashed. Open task logs. Image must listen on 0.0.0.0:8080
  (the lecture 6 notes-api file already does).

Money scare
  Fargate + ECR + one micro for one class is cents to a couple of dollars
  if you delete today. NAT from lecture 4 is the expensive leftover — delete that too
  if it is still running.
